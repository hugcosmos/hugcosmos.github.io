Nicky — AI product engineer, independent.

I build AI products end to end: speech pipelines, agents, and interactive teaching. What I ship goes to GitHub, and I write down the trade-offs rather than the feature list.

What I'm working on now

Speech tooling: multi-provider TTS, real-time recognition and scoring, and the small utilities that make them usable. The current focus is turning Scripts to Audiobook and SceneLine into something a non-developer can run.

Stack

TypeScript and React on the front end; Python and FastAPI on the back end; FunASR and Edge TTS for speech; Docker for deployment; SQLite when a project needs persistence.

How I work

Constraint first, then the smallest thing that survives it. AI writes much of the code with me, but the shipped product does not depend on a model at runtime: if the network is down, it still runs.
