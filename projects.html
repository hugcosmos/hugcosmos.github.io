Open Source Projects

Seven open-source repositories plus two coursework projects, ordered by what you can try right now, engineering completeness and problem difficulty. Every entry links to something you can open.

CodeMath

An interactive platform for computer-science mathematics: nine chapters rebuilt as hands-on demos — base converter, logic-gate playground, truth-table generator, induction dominos, Tower of Hanoi, fractals and a halting-problem simulator.

React 19 · TypeScript · Three.js · GSAP · KaTeX · MIT

GitHub Live Demo

SceneLine

An AI dubbing practice platform for language learners: real-time ASR with a resident FunASR process, 40+ Edge TTS voices filtered by gender and locale, multi-character scenes with per-role scoring, and Docker deployment with data persistence.

Node 20 · Python · FunASR · Edge TTS · Docker · MIT

GitHub

Scripts to Audiobook

Turn formatted scripts into multi-voice audiobooks across four TTS providers (Edge, ElevenLabs, iFlytek, Baidu), with a weighted voice-matching engine, a 61-voice catalog, album-based library management, and merged MP3 + SRT output.

FastAPI · React · SQLite · 4 TTS providers

GitHub

Podcast Studio

Topic in, episode out: news search and a multi-turn script via Perplexity sonar-pro, distinct Edge TTS voices per turn, merged into one MP3 with ffmpeg — a finished episode in about two minutes.

Python · FastAPI · Perplexity · Edge TTS · ffmpeg · Docker

GitHub

Book to Audiobook

Convert EPUB, MOBI, AZW3, PDF and TXT into chapter-marked M4B or MP3 audiobooks, with selectable TTS providers and a pip-installable command line.

Python 3.11+ · ffmpeg · Calibre · PyPI

GitHub

MovieFairy

A gentle movie recommender: three questions map your mood onto nine strategies drawn from mood-management theory, then sample from the top candidates. Pure static, PWA, no backend or API calls.

Vanilla JS · Cloudflare Pages · PWA

GitHub Live Demo

Edge Read Chrome (ReadAloud)

A Chrome extension that reads pages aloud with Edge neural voices and word-by-word highlighting, using native messaging instead of the Web Speech API, plus site-specific extraction for WeRead, ChineseAll, QQ Reading and Douban.

Chrome MV3 · Native messaging · edge-tts

GitHub
